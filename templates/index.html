ABOUT THE PROJECT

Machine learning + Flask + modern frontend.

EstateIQ is a house price prediction project that connects a Flask backend with a Random Forest regression model. The model uses area, BHK, bathrooms, square footage and property age. Predictions are only generated for locations represented in the training dataset.
